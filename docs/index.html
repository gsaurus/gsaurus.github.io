Streets of Rage 2 New Era Modding Docs¶

Welcome to the modding documentation for Streets of Rage 2 New Era.

These docs cover the full modding workflow: playing mods made by other people, creating and exporting your own mods, editing characters, building levels and cutscenes, replacing classic game content, adding audio, creating palettes, and using Lua scripts when editor-driven behavior is not enough.

Choose Your Path¶

  • I want to play a mod: start with Installing Community Mods.
  • I want to make a full custom mod: follow Create a Custom Mod.
  • I want to reskin the classic game: start with the Reskin Workflow.
  • I want to edit a character: open the Character Editor docs.
  • I want to build levels or cutscenes: open the Level Editor docs.
  • I want to replace music or sounds: open the Audio Editor docs.
  • I want to script behavior: start with Lua Scripting.

How the Docs Are Organized¶

The site has two main learning paths.

The Editors section documents each tool as a reference: the in-game editor, Character Editor, Level Editor, Audio Editor, and Lua scripting. Use this when you want to understand a screen, setting, panel, or file.

The Build a Mod and Reskin the Classic Game sections are practical guides. Use them when you have a concrete goal, such as creating a playable character, adding cutscenes, replacing classic music, or exporting a mod for friends.

Important Folders¶

  • Mods: exported mods ready to play.
  • Editor: source mods that can be opened from the in-game editor menu.
  • Entities: custom characters, enemies, items, and containers inside a source mod.
  • Levels: custom level art, level definitions, cutscenes, and special screen data.
  • Sounds and Musics: custom audio used by mods.
  • Palettes: color palettes created in the built-in palette editor.
  • Scripts: Lua scripts used by character logic, events, and custom behavior.

Multiplayer Compatibility¶

When playing a mod online, every player must use the same exported mod version. New Era checks whether the mod checksum matches, so a tiny file difference is enough to make two copies incompatible.
