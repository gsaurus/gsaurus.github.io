Playable Character From ROM Hack¶

The Character Editor can import character data from a Streets of Rage 2 ROM file, including supported ROM hacks, and convert it into a New Era entity you can edit.

ROM import only supports ROM hacks made from the US/western version of Streets of Rage 2. ROM hacks made from the Japanese version, Bare Knuckle 2, or from more complex ROM hacks such as Streets of Rage 2 Syndicate Wars, are not supported.

Goal¶

Use a ROM hack as a starting point for a playable character, then finish the character with New Era tools.

Prerequisites¶

  • A source mod under Editor.
  • A ROM file you are allowed to use.
  • The ROM file is in a supported Genesis/Mega Drive format such as .bin, .gen, .md, or .smd.
  • The ROM hack is based on the US/western Streets of Rage 2 ROM.

Steps¶

  1. Open the mod in the in-game editor menu.
  2. Launch the Character Editor.
  3. Drop the mod folder into the Character Editor if prompted.
  4. Choose Mod mode.
  5. Drop the ROM file into the Character Editor.
  6. In the import dialog, choose Players.
  7. Select the character to import.
  8. Give the imported character a New Era name.
  9. Open the new character from the list.
  10. Review the imported animations, pivots, boxes, logic, and sprites.
  11. Save the character.

Clean up after import¶

Imported data is a starting point, not a finished release.

  • Rename animations so you can find them later.
  • Check pivots on every important movement and attack frame.
  • Check hitboxes, body boxes, throw data, and attack sounds.
  • Replace or add portraits, previews, palettes, and missing sprites.
  • Remove unused frames or animations once the character is stable.
  • Add New Era-specific events, scripts, or audio if the character needs them.

Testing¶

  • Test the imported character in a simple level.
  • Compare basic moves against the ROM hack behavior you expect.
  • Confirm attacks, throws, jumps, damage reactions, and death all work.
  • Test with Classic enemies and with another custom character.
