Editors Reference¶

Start in the game's mod editor: create or select a mod, then open the tool for the content you want to change. Each tool writes into that mod's folder.

The standalone editors save changes automatically. Make a copy of your mod before a large experiment. The in-game Gameplay Rules screen has explicit Save Rules and Cancel buttons.

Editor Areas¶

  • In-Game Mod Editor - create mods, configure settings, edit palettes, open the bundled tools, test, and export.
  • Character Editor - create new characters or replace classic character visuals.
  • Level Editor - create new levels or reskin the classic ones. Title screen and character select screen is also configured here.
  • Audio Editor - add custom sounds and music or replace classic music, voices, and SFX.
  • TAS Editor - build a frame-by-frame tool-assisted run and inspect the game state as it plays.

Common Workflow¶

  1. Open the in-game editor and either create a new mod or choose an existing mod.
  2. Configure mod settings and optional difficulty settings.
  3. Use Open Tools to launch the Character Editor, Level Editor, or Audio Editor for the selected mod.
  4. Edit color palettes when needed.
  5. Use Test Mod regularly to play the mod with the same data the game will load, except for color palettes.
  6. When the mod is ready, export it.

Mode Terms¶

Several tools ask whether you want to edit Mod content or Classic Reskin content.

Mod mode adds new content to your mod, such as new characters, new levels, custom sounds, and custom music.

Classic Reskin mode replaces content from the original SOR2 while keeping the original gameplay intact.

For tool-specific differences, see Mod Characters vs Classic Reskin, Mod Levels vs Classic Reskin, and Mod Audio vs Classic Reskin.

See Editor feature coverage for remaining gaps and settings that still need a configuration file.
