Create New Mod¶

Use Create New Mod from the in-game editor's mod selector to start a new editable mod. The game creates a draft mod folder and opens the settings screen so you can name and configure it before editing content.

Creating a Mod¶

  1. Open the editor from the game's editor menu.
  2. Choose Create New Mod from the mod list.
  3. Enter a mod name. The name becomes the display name and the mod's folder name.
  4. Add a description if you want players to understand the mod's purpose from the mod list.
  5. Choose whether the mod has gameplay settings. If it does, the mod can define difficulty data and gameplay rules.
  6. Confirm to create the mod.

If the chosen name is already in use, the editor creates a unique draft name first. Rename it from Mod Settings before doing heavy editing, because tool folders and replacement data use the mod name as part of their references.

First Decisions¶

New mods do not need all content types. A mod can be only audio replacements, only a character pack, a level pack, a palette set, a script pack, or a full game overhaul.

Before opening tools, decide whether you are adding new content or replacing classic content:

  • For characters, see Mod Characters vs Classic Reskin.
  • For levels, see Mod Levels vs Classic Reskin.
  • For audio, see Mod Audio vs Classic Reskin.

After Creation¶

After the mod exists, use Open Tools to launch Character Editor, Level Editor, and Audio Editor for that mod. Use Test Mod frequently while building so problems are found before Export Mod.
