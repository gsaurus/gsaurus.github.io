Level Editor¶

The Level Editor edits stage structure, scene logic, background art, cutscenes, spawns, walls, scroll limits, collision, music, and special screens. It is launched from the selected mod's in-game editor menu and saves into that mod folder.

Use it in Mod mode to create your own levels and cutscenes. Use it in Classic Reskin mode to replace original SOR2 level art, cutscenes, title screen, character select screen presentation, and ending-style screens while keeping classic level structure.

Mod Levels vs Classic Reskin¶

Read Mod Levels vs Classic Reskin before building a level set. The mode you choose affects whether you edit level gameplay data or only replacement art/special screens.
