The Inspector¶

The Inspector is the right-hand panel. It always shows the settings for whatever you last selected, so its contents change as you click around: select the character and you get character-wide settings; select an animation and you get animation settings; select a frame and you get that frame's boxes, events and throw data.

Every field in the editor has a tooltip. This page is the same information organised so you can find a setting when you do not yet know what it is called.

Sections are collapsible — click a section header to expand or collapse it. Sections that were added optionally (Script, Behaviour, Throw Logic, Weapon) also have a remove button that deletes the section and everything in it.

Character Settings¶

Shown when the character itself is selected, rather than a specific animation or frame.

Visual Settings¶

How the character is drawn.

Field Meaning
Scale Size multiplier applied to every sprite when drawn in game. 1 keeps sprites at original size.
Shadow Always On The character always casts a shadow, even in animations where it would normally be hidden.
Icon Sprite used as the character's portrait in menus such as character select. Drop an image here to add it and use it as the icon.
Icon Offset X / Y Shift of the icon sprite relative to its pivot, in pixels. Use it to centre the portrait in menus.
Use Sprites from Mod providing fallback sprites. Any animation frame without its own sprite falls back to the character picked below.
from Character Character inside that mod whose sprites and animations are used as the fallback.

Logic Settings¶

How the character behaves. Not every field applies to every entity type.

Field Meaning
Ref Mod Mod providing the behaviour this character inherits. Leave empty to use Classic content.
Ref Name Character inside the reference mod whose behaviour is inherited when this one has no logic of its own.
Entity Type Player, Enemy, Basic Enemy, or Item. Decides how the game spawns and controls it.
Walk Speed Movement speed while walking.
Run Speed Movement speed while running.
Jump Force Upward impulse on jump. Higher jumps higher.
Jump Delay Game frames between pressing jump and leaving the ground.
Can Use Weapons Whether the character may pick up and use weapons.
Combo Repetitions How many times the standard attack combo can repeat before resetting.
Grab Combo Repetitions How many times the grab attack combo can repeat before resetting.
Charge Delay Game frames the attack button must be held before the charged move becomes available.
Grab Range How close an opponent must be to be grabbed.
Front / Back Grab Offset Distance at which a grabbed opponent is held, when grabbed from the front or from behind.
Knockdown Quake Screen shake strength when this character hits the ground after a knockdown. 0 disables it.
Thrown Quake Screen shake strength when this character lands after being thrown. 0 disables it.

Projectile fields (Damage, Hit Pause) appear here for characters that spawn projectiles. Hit Pause is how many game frames both characters freeze for when the projectile connects — it is what makes a hit feel heavy.

Global Body Box¶

The character's default body box, used by any frame that does not define its own.

Field Meaning
X Left edge, in pixels relative to the character's origin.
Y Bottom edge, in pixels relative to the origin.
Width Width in pixels. The left edge stays put as the box grows.
Height Height in pixels.
Depth Depth along the towards/away axis. Controls how far apart two characters can be and still collide.

See Body and Hit Boxes for how this interacts with per-frame boxes.

Sounds¶

Default sounds for common actions: Run, Jump, Landing, Attack, Jump Attack, Weapon Throw, Blitz, Defensive Special, Offensive Special, Grab Move 1/2/3, Quake, Low Health, Death, Last Life Death.

Each is a list. When more than one sound is listed, the game picks one at random — this is how you stop a repeated action from sounding mechanical. Use the pick button to browse sounds in the mod rather than typing names.

See Audio Events.

Entity Scripts¶

Lua hooks for the whole entity, shown whether or not the character uses reference logic. Each one picks a script from the mod's Scripts/ folder, with an optional Mod Name; the x on its header removes it. The Add buttons offered depend on the Entity Type, but a hook that is already set is always shown.

Section Meaning
AI Script Enemies: runs every frame before the built-in AI, whatever the animation. Returning false skips the built-in AI for that frame.
Pickup Script Items: runs when a player picks the item up. Returning true consumes the item.
Player Update Script Players: runs once per frame before the player's controller, in every animation.
Special Move Script Players: decides whether a defensive or offensive special may start, and its cost.
HUD Script Players: view-only script drawing extra HUD sprites next to the health bar.
Invincible Offensive Special Players: offensive specials start invulnerable, without the classic vulnerable window.
No Charge Flash Players: no white flash when holding attack completes the charge (noChargeFlash). The charged attack still works.

Animation Settings¶

Shown when an animation is selected.

  • Name — the name shown in the animation list.
  • Afterimages — draws a trail of afterimages behind the character during this animation, like the Ninpo clones. Visual only.
  • Script — an optional custom Lua script driving this animation's behaviour. Added with Add Script Data, removed with Remove Script (which detaches it; the script file itself is not deleted).
  • Behaviour — an optional override making this animation borrow an original SOR2 entity's behaviour. Added with Add Behaviour Override. See Behaviour Modes.

Frame Settings¶

Shown when a frame is selected in the timeline.

Field Meaning
Image ID Sprite drawn on this frame. Changing it swaps the artwork without touching timing or logic.
Duration How long this frame stays on screen, in game frames.

Sprite Offset¶

Offset X / Y position the sprite relative to the character's origin, in pixels. Negative X moves left, negative Y moves up.

This offset is shared by every frame using the same sprite. That is the whole reason it exists as a separate concept from the pivot — see Pivots and Offsets.

Weapon¶

Where a held weapon is drawn on this frame. Enable it with the checkbox; turning it off remembers the settings, so you can turn it back on without losing them.

Field Meaning
X / Y Position of the weapon point, in pixels relative to the character's origin.
Direction Direction the held weapon points in on this frame.
Show Behind Draw the weapon behind the character on this frame instead of in front.

Hitboxes¶

Areas that damage opponents during this frame. A frame can have several, each with its own timing and damage.

Field Meaning
Relative Frame Game frame, counted from the start of the selected sprite frame, on which this hitbox becomes active. 0 is the first frame.
Duration How many game frames the hitbox stays active.
Damage Damage dealt to an opponent caught by this hitbox.
Knockdown The hit knocks the opponent down instead of just staggering them.
Hit Backwards The opponent is knocked away from the direction this character faces, rather than towards it.
Hit Pause Game frames both characters freeze for on a successful hit.
Sound ID, Sound Mod, Sound Channel The impact sound for this specific hitbox.
Classic Hitbox Use the original SOR2 hit detection instead of the editor's own box.
X / Y / Width / Height The box itself, in pixels.

Bodyboxes¶

Areas that can be hit during this frame. Same Relative Frame and Duration timing as hitboxes, plus X, Y, Width, Height — where X is the left edge and Y the bottom edge, and the left edge stays put as the width grows.

Events¶

Things that happen at specific moments of this frame — movement, sounds, spawning, jumping to another animation. Add one with the add button, which opens a searchable list of event types.

Each event row can be expanded to show its settings or removed. See Logic Events and Logic Event Examples.

Throw Logic¶

How the character carries and releases an opponent during this animation. Added with Initialize Throw Logic; Remove Throw Logic deletes it along with all its opponent offsets.

Field Meaning
Release Damage Damage dealt by the projectile at the moment it is released.
Legacy Mechanics Use the original SOR2 movement and combat rules for this character instead of the newer ones.
Relative To Attacker Hold the opponent relative to this character's current position and height, without the classic grab distance. Use it, with Legacy Mechanics off, for aerial or moving throws.
X / Y Release velocity.

Offsets hold where the carried opponent is positioned at each moment of the throw:

Field Meaning
Relative Frame Frame, counted from the start of the selected sprite frame, on which this offset applies.
Opponent Anim Animation the held opponent is put into while this offset applies.
Opponent Frame Frame of that animation to show.
Same Direction The opponent faces the same way as this character instead of facing them.
X / Y Distance the opponent is held at, in pixels. Positive X puts them in front; positive Y moves them up.

You can drag the opponent directly in the preview instead of typing these values.

Axis Conventions¶

Wherever a field has X, Y and Z components, the editor uses one consistent convention:

  • X — forward and backward. Positive is forward, in the direction the character faces.
  • Y — up and down. Positive is up, as shown in the editor.
  • Z — towards and away from the camera (the belt-scroller depth axis).

Movement events (Set Velocity, Set Acceleration, and their input-driven versions) have a checkbox per axis. When an axis checkbox is off, that axis value is ignored and the character's existing movement on that axis is left alone. This lets you zero one component without disturbing the others.
