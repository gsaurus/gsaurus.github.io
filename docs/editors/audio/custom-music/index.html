Custom Music¶

Custom music is used by levels, cutscenes, character events, scripts, and Classic Reskin music replacements.

Adding Music¶

  1. Open the Audio Editor from the in-game editor menu.
  2. Choose Mod.
  3. Open the Music tab.
  4. Drag WAV, MP3, or OGG files into the list.

The editor copies files into the mod's Musics folder. The file base name becomes the music name used by the Level Editor and character logic events.

Music Metadata¶

When you enable a loop point, the editor saves a small JSON file beside the music file. The metadata stores loopStartTimeInSeconds and loopEndTimeInSeconds, which the game uses when looping the track.

Use Loop Points for detailed loop editing.

Assigning Music¶

Use the Level Editor's Scene Settings to assign scene music. Use Audio Events if a character animation should trigger music directly.

Practical Advice¶

Keep music names stable once assigned. If you rename a music file, you have to manually update all scene settings, logic events, and replacement mappings that point to it.

Test music in-game after adding it.

Related pages: Replace Classic Music, Test Mod.
