The Audio Editor Workspace¶

The Audio Editor opens on a Choose what to edit screen with two cards: Mod and Classic Reskin. The choice changes which tabs exist, so it is not a cosmetic mode switch. The 🏠 button returns you to this screen at any time.

Imports, replacement assignments and loop settings save automatically.

Tabs by Mode¶

Tab Mod mode Classic Reskin mode
Sounds Your mod's sound library Your mod's sound library
Voice — Replacements for original voice entries
Sfx — Replacements for original SFX entries
Music Your mod's music library Replacements for original music entries
Loop Points — (loops are edited from the Music tab) Loop editing for tracks used as replacements

In Mod mode the last tab is called Music and holds your tracks. In Classic Reskin mode that same tab becomes Loop Points, and it lists only the music currently used by replacements — the editor says as much on the tab itself.

Replacement tabs show how many entries are assigned in their title, so you can see progress without opening each one.

Adding Audio¶

Drag WAV, MP3 or OGG files onto the relevant list. The editor copies them into the mod — Sounds or Musics — and the file base name, without the extension, becomes the name other editors use to reference it.

Dropping onto a replacement field does two things at once: it adds the file to your mod and assigns it as that replacement.

Duplicate handling is automatic. If a dropped file matches an existing one by checksum, the editor reuses the existing file rather than storing it twice. If the name collides but the audio differs, it generates a unique name.

Replacement Entries¶

Each entry in a replacement tab has:

  • A picker button — click to choose from the mod's audio, or drop a file directly onto it.
  • A preview button — plays the assigned replacement; click again to stop. Disabled when nothing is assigned.
  • A None option in the picker — clears the replacement so the original Classic audio is used again.

Every list has a search box that filters to entries whose name contains the text.

The Waveform Timeline¶

The timeline is where loop points are set. It is a zoomable, scrollable waveform with three draggable markers.

Input Action
Wheel up / down Zoom in / out by 15% per notch, anchored at the pointer.
Right-drag or Middle-drag Scroll along the track.
Left-drag on empty space Scroll along the track.
Left-click on empty space Seek playback to that point.
Left-drag on a marker Move that marker.

The click-to-seek is distinguished from a scroll by both distance and time: a press that moves less than a few pixels and releases within about a third of a second counts as a click. If seeking is not working, you are probably dragging slightly.

Zoom ranges from fully zoomed out to roughly 1000×, which is enough to place a loop point on an individual transient. At high zoom the time ruler switches to a finer format automatically.

The Three Markers¶

  • Loop Start (red flag) — the point the music jumps to.
  • Loop End (blue flag) — the point the music jumps from.
  • Playhead — the current playback position.

Markers are grabbed within about 15 pixels, and they have a fixed priority when they overlap: Loop End wins, then Loop Start, then the playhead. This matters when a loop is very short or you are zoomed out — if you cannot grab the marker you want, zoom in until they separate.

Markers highlight on hover, so you can confirm which one you are about to grab before pressing.
