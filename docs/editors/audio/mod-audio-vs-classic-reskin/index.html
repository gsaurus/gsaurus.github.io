Mod Audio vs Classic Reskin¶

The Audio Editor starts by asking what you want to edit: Mod audio or Classic Reskin audio.

Mod Audio¶

Use Mod to add and manage all sounds and music included with your mod.

Mod audio is useful for:

  • Character voices and attack effects.
  • Custom enemy, item, weapon, or projectile sounds.
  • Music used by custom levels.
  • Music triggered by character logic events.
  • Shared audio that scripts or editor events reference by name.

In Mod mode, the editor shows sound and music lists. Drag WAV, MP3, or OGG files into the appropriate tab. The file base name becomes the audio name used by other editors.

Classic Reskin Audio¶

Use Classic Reskin mode to replace original SOR2 voice, SFX, and music entries. This mode shows replacement tabs for Voice, SFX, and Music. Drop audio onto a replacement entry or choose an existing sound/music from the mod.

Classic Reskin audio is useful for:

  • Replacing original stage music.
  • Replacing original character voices.
  • Replacing common SFX.
  • Creating a complete audio reskin for classic based mods.

Shared Music Loop Editing¶

For Mod mode, loop points are edited directly from the music list. In Classic Reskin mode, the music list shows the original music replacements. There is an additional loop points tab for editing the loop start and loop end of the music used as replacements.
