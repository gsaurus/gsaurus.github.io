Installing Community Mods¶

Mods are usually shared as exported .cne files. You might find them through community links, such as links shared on the Streets of Rage 2 New Era Discord.

Goal¶

Install a shared mod into your game and know what to do if the author sends editable source files instead.

Where the Mods folder is¶

Platform Mods folder
Windows Mods, next to the game's executable
Linux Mods, next to the game's executable. If that folder can't be created, ~/.config/unity3d/gsaurus/SOR2 New Era/Mods
macOS ~/Library/Application Support/gsaurus/SOR2 New Era/Mods
Android Private to the game. Use Extras -> Add Mods (see below)

On macOS and Linux, Extras -> Add Mods can also switch to a different Mods folder: select a folder instead of mod files.

If you received an exported mod¶

On Windows, macOS and Linux:

  1. Download the mod file. It is usually a .cne file.
  2. Close the game if it is already running.
  3. Move the .cne mod file into the game's Mods folder.
  4. Run Streets of Rage 2 New Era.
  5. The game scans Mods automatically and adds the mod to the available mod list.
  6. Select either Local Game or Online Game, then select the mod from the list to play.

On Android, or to skip finding the folder on macOS and Linux:

  1. Download the mod file (.cne or .zip).
  2. In the game, open Extras -> Add Mods.
  3. Browse to the downloaded file and select it. You can select several at once.
  4. The game copies the mod into its Mods folder and loads it right away. Adding a mod with the same name replaces the previous version.

On Android 10 and newer, the file browser first asks for a folder through the system picker: choose the folder you downloaded the mod to, such as Download.

If the mod does not appear¶

  • Confirm the file is in Mods, not Editor. On macOS and Linux, check the table above: the folder is not always next to the game.
  • Confirm the file has the .cne extension.
  • Restart the game if you didn't after adding the mod in the Mods folder.
  • If the game reports missing or mismatching dependencies, download the required dependency mods and also add them to the Mods folder. Make sure you got the correct versions.

If you received source files¶

Source mods are simply folders with content inside. Opening and editing them needs the in-game editor, which is only available on Windows. On other platforms, ask the author for the exported .cne file.

  1. Place the whole source folder in Editor (unzip it first if you downloaded it as a .zip file).
  2. Run Streets of Rage 2 New Era.
  3. Open the in-game editor menu (Extras -> Editor).
  4. Open the mod from the editor list.
  5. Test or export it from the editor.

The source folder should normally contain config.json and may contain folders such as Entities, Levels, Sounds, Musics, Palettes, or Scripts.

Multiplayer¶

Both players need the same mod version. New Era compares mod checksums; the mod name alone is not enough.

If multiplayer reports a missing mod or mismatching checksums, the players must exchange the same version of the mod and then restart the game.
