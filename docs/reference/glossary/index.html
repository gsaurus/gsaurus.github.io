Glossary¶

Animation Logic¶

Per-animation data in logic.json: duration, hitboxes, body boxes, throw logic, events, scripts, and animation behaviour.

Behaviour Mode¶

The objectMode value used by Classic move controllers. It selects behaviour routines for players, enemies, and items. See Behaviour Modes.

Character¶

The combat layer shared by players and enemies. It owns health, damage, grabs, victims, attackers, combo state, and score-related helpers.

Classic¶

The built-in Streets of Rage 2 content pack used as the target for Classic reskins.

Classic Reskin¶

A pack that keeps Classic gameplay structure and replaces presentation assets such as art, entities, palettes, music, and sounds.

Content Pack¶

A named set of mod content. During editing, content packs usually live in Editor/<Pack Name>.

Entity¶

A playable character, enemy, item, pickup, projectile, container, or scenery-like object with sprite, animation, and logic data.

Entity Replacement¶

A replacement entity folder targeting another pack's entity, such as Entity Replacements/Classic/Axel.

Event¶

A frame-bound animation action stored in logic.json, such as playing a sound, changing velocity, spawning an item, or jumping to another animation.

Item¶

The physical layer of an entity. It owns position, velocity, impulses, active state, collision state, and vulnerability.

Layer¶

A level-art layer with parallax, scroll, z-order, images, and optional animations.

LocalLevelBackgroundData¶

JSON structure used for level art, cutscenes, title screens, presentation screens, and endings.

Pack Name¶

The folder name of an editor pack. Scripts, audio references, palettes, and dependencies often use it exactly.

Palette Provider¶

A palette image available to an entity. In this documentation, added playable-character palettes live under Palettes/Classic/<Playable Character>.

Animation Behaviour¶

Animation logic that delegates to Classic behaviour for a referenced entity, using packName, type, animationId, and objectMode.

ScriptData¶

JSON reference to a Lua script:

{
  "packName": "My Pack",
  "scriptName": "My Script"
}

Skin¶

The Classic reskin layer that supplies replacement title, presentation, ending, cutscene, and level-art files from Level Replacements/Classic.

SubItem¶

The visual and animation layer of an entity. It owns animation IDs, frames, palette state, facing direction, object mode, and custom values.
