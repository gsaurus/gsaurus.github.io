Enums and Identifiers¶

Every numeric constant the JSON files use, in one place, plus the identifier tables you need to reference Classic content.

Animation slots¶

animations.json animations and logic.json animationsLogic are indexed by animation id. For entities built on Classic behaviour, animation id i corresponds to the original AnimationId value i * 2.

Everything that names an animation — JumpToAnimationEvent.animationId, OffsetData.opponentAnimation, SpawnItemEvent.animationId, ReferenceBehaviourData.animationId — uses the id in the first column.

Entity types¶

logic.json entityType:

Value Name Meaning
0 Player Playable character.
1 BasicEnemy Common street enemy. The difficulty system may multiply these.
2 Enemy Boss-class enemy.
3 PickUpItem Weapon, food, or score pickup.
4 Container Breakable object holding something.
5 Scenery Non-interactive object.
6 Other Anything else, such as effects.

The Character Editor only offers 0-3. Values 4-6 are authored by hand or produced by the ROM importer.

Audio channels¶

channel on SoundEvent, HitboxData, and projectileHitSoundChannel:

Value Name
0 sfx
1 sfxBgm
2 voice
3 prioritary

Sounds sharing a slot cut each other off. The runtime treats the value as a plain index and allocates as many slots as it encounters, so any non-negative number is a valid private channel — useful when a sound must not be interrupted by anything else. Existing mods use values well above 3 for exactly this.

Input buttons¶

JumpToAnimationOnInputButton.input is a flag value from InputButtons:

Value Button Value Button
1 Up 256 Hold Up
2 Down 512 Hold Down
4 Left 1024 Hold Left
8 Right 2048 Hold Right
16 B 4096 Hold B
32 C 8192 Hold C
64 A 16384 Hold A
128 Start 32768 Hold Start
65536 X 262144 Hold X
131072 Y 524288 Hold Y
1048576 Z 4194304 Hold Z

0 is Empty.

Input combos¶

JumpToAnimationOnInputCombo.input is a string, one character per step, matched in order:

Character Step
^ Up
v Down
< Left
> Right
a b c x y z Face buttons

Parsed case-insensitively. Left and right mirror with facing, so a combo authored facing right also works facing left. Any other character is ignored as an Empty step, which will never match.

Examples: "vv" is down, down. "v>a" is down, forward, A.

Classic entity names¶

The Classic pack is extracted from the original ROM. Use these exact names in entityName, in Entity Replacements/Classic/<name>/ folders, and in Palettes/Classic/<name>/ folders.

Players: Max, Axel, Blaze, Skate.

Enemies: Galsia, Donovan, Jack, Barbon, Electra, Signal, Biker, Ninja, Bongo, Hakuyo, Kickboxer, Jet, Zamza, R.Bear, Abadede, Particle, Mr.X, Shiva, Ninja (Kunai), Ninja (Sword), Blast, Vehelits, Vehelits (2).

Enemy variants: Galsia (2), Galsia (3), Barbon Jacket.

Weapons and pickups: Knife, Pipe, Sword, Kunai, Grenade, Cash Bag, Gold Bars, 1UP, Apple, Chicken.

Containers and scenery: Bin, Manhole, Lamp, Menu, Table, Table (2), Table (3), Table (4), Chair, Trash Can, Oil Barrel, Truck door debris, Truck door debris (2), Electric box, Electric box (2), Barrier, Light, Arcade, Ship Pole, Obj 2, Obj 3, Obj 4, Obj 5, Sandbag, Sandbag (2), Sandbag (3), Sandbag (4), Crate, Metal Crate, Vase, Alien Egg.

Interface and effects: Arrow, 1P, 2P, Go, Sunset Alphabet, Shadow, BlueHit, SmallHit, BigHit, GroundDust.

Names are matched exactly, including spaces, capitalisation, and punctuation. R.Bear has no space; Ninja (Kunai) has one before the bracket.

The name hash¶

Pack names and entity names are reduced internally to a 32-bit signed hash. You never need to compute this yourself except for allowedCharacters in config.json, which stores hashes rather than names.

hash = 23
for each character c in the name:
    hash = (hash * 31 + codepoint(c))  wrapped to signed 32-bit

An empty or null name hashes to 0.

A pack with an id is identified by the hash of its id instead of its name: the same function over the id in its canonical form, lowercase and hyphenated (3f6c2a9e-8b1d-4c57-9e2f-7a0d5b4c1e88).

In Python:

def name_hash(name: str) -> int:
    if not name:
        return 0
    h = 23
    for ch in name:
        h = (h * 31 + ord(ch)) & 0xFFFFFFFF
    return h - 0x100000000 if h >= 0x80000000 else h
